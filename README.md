# Iris Flower Classification

## Project Description
This is a Machine Learning application
that predicts the type of Iris flower
using its measurements.

## Technologies Used
- Python
- Streamlit
- NumPy
- Pandas
- Scikit-learn

## Algorithm
Random Forest Classification

## Dataset
Iris Dataset

## Features
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

## Output
The application predicts:
1. Iris Setosa
2. Iris Versicolor
3. Iris Virginica

## How to Run
1. Install required libraries.
2. Open the project folder.
3. Run the command:

python -m streamlit run app.py
